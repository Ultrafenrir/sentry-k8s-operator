T01 — SOURCE-ONLY V1ALPHA1 CONTRACT
Date: 2026-10-29
Status: Complete for ADR 0001 scope

T01 created the Kubebuilder project, pinned dependencies, and published two resources:

- cluster-scoped `SentryConnection` for platform credentials, transport, organization,
  compatibility, integration defaults, and access policy;
- namespaced `SentryProject` for create-or-use identity, DSN output, typed settings,
  destinations, alerts, pause, and lifecycle.

The schema requires exactly one project identity mode, bounds strings/maps/lists, rejects
unsafe transport combinations, and uses CEL plus admission webhooks for cross-field rules.
Status is a subresource and excludes Secret values and private external identities.

Generated CRDs, DeepCopy code, RBAC, and webhook manifests are reproducible through
`make manifests generate`. Published samples pass real API-server admission on the pinned
envtest matrix.

T01 deliberately did not implement reconciliation or Sentry HTTP behavior. Those concerns
belong to T02 and later tasks. A second API version requires ADR 0002's conversion and
storage migration contract.
