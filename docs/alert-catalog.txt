SENTRY CONFIGURATION OPERATOR — ALERT CATALOG
Source review: 2026-10-29
Status: Legacy 24.7.1 and modern 26.10.1 source catalogs are implemented for the bounded
alpha surface. External action delivery is not proven by this catalog.

1. Usage rule

The CRD exposes adapter-neutral alert intent. A Sentry-version adapter maps that intent to a
legacy issue rule, legacy metric rule, or modern metric detector/workflow. Unknown trigger
families fail closed. Raw Sentry rule or workflow JSON is not accepted.

2. Legacy issue alerts — Sentry 24.7.1

Supported common triggers:

- `first-seen`: issue first seen;
- `regression`: issue changes from resolved to unresolved.

These use the legacy project rule collection. A readable local destination is resolved and
pinned before an action is written. Disabled state is not represented by deleting an issue
rule; the alpha contract rejects unsupported disable semantics.

3. Legacy metric alerts — Sentry 24.7.1

Supported common triggers:

- `event-count` with `windowMinutes` and `threshold`;
- `user-count` with `windowMinutes` and `threshold`, rendered as
  `count_unique(user)`.

The adapter uses the legacy alert-rule and trigger/action collections. Identity and mutation
state are kept in protected bindings so interrupted creates and cleanup can be retried
without duplicating rules.

4. Modern detector/workflow — Sentry 26.10.1

Supported common triggers:

- `event-count`, represented by an events/count() metric detector attached to a workflow;
- `user-count`, represented by an events/count_unique(user) metric detector attached to a
  workflow.

The adapter supports create, read, update, enable/disable, and guarded delete. The detector
and workflow are treated as one owned logical alert in Kubernetes status. Detector families
other than the verified metric detector remain unsupported.

5. Evidence boundary

Sanitized request/response fixtures and adapter tests establish request shape and response
parsing. Live configuration acceptance establishes object lifecycle. Neither establishes
Slack, PagerDuty, Telegram, or Alertmanager delivery. Sentry 26.10.1 returns 404 for the
legacy collection routes; legacy live acceptance belongs on 24.7.1.
