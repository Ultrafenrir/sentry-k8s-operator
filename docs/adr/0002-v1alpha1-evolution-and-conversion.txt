ADR 0002 — V1ALPHA1 EVOLUTION AND CONVERSION
Date: 2026-10-29
Status: Accepted

Decision

The repository serves and stores only `sentryconfiguration.io/v1alpha1` until a second API
version has a real consumer and a proven migration contract. Additive optional fields may be
introduced when their zero value preserves existing behavior. Existing field meaning,
defaulting, ownership, or security boundaries must not change silently.

A second served version requires:

- explicit hub/spoke selection;
- bidirectional conversion tests for every published field;
- storage-version migration and rollback evidence;
- unknown-field and defaulting compatibility tests;
- an ADR that explains information loss and downgrade behavior.

Webhook conversion endpoints are intentionally absent while only one version is served.
This avoids a non-functional conversion promise and keeps installation dependencies small.
